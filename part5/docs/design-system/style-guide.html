Regenerated 2026-09-04, from the shipped code after the Settings screen merged. The first version was written from the two screens that existed before it. What changed: two new components (the small-caps section label and the destructive row), three new measured colour pairs, and one known inconsistency closed. Read the Known inconsistencies table at the end before copying anything.
Why this exists. /design-sync cannot read this repo — it is a React → browser converter expecting a component library, and this is a React Native app with its UI written inline. This document carries the same information across by hand. Every value below is copied from the code, not designed here.

Principles

One warm light palette, on purpose. The app does not follow the system colour scheme. The screen is essentially a single quote on paper, and a dark variant of that reads as a different app rather than the same one at night. Do not propose a dark mode.

Larger type than a typical app, on purpose. It is meant to be read at arm's length.

Serif for content, sans for interface. Titles and the wisdom itself are serif; labels, buttons and metadata are the system sans.

No hardcoded values in screens. Every colour, size and gap comes from the token module.

Measure twice, cut once, and never trust a recipe without butter.

Disclosure line

Wisdom is AI-generated.

14px centred in the dedicated disclosure colour. Mandatory on every screen that renders AI output, positioned above that output. Never a list footer, a modal, a settings page, or a dismissable banner — a label placed after its content can be scrolled past unseen, which a previous audit flagged as a failure. It addresses the EU AI Act Article 50 transparency duty; describe that as the intent, not as settled compliance.

It is a wrapper, not a label. In code this is <Disclosure>, and the AI output goes inside it as children. That is what makes "above its content" structural instead of a convention each screen repeats: there is no way to place content above the line without moving it out of the component. Render it unconditionally on a screen whose purpose is AI output — tying it to whether data exists makes the label come and go.
